# План: Загрузка подготовленного шаблона тренировки на телефон (Gym Tracker PWA)

## Цель
Определить и реализовать наиболее удобные способы загрузки предварительно подготовленных шаблонов тренировок (например, файлов вроде `gym-tracker-import-4days.json` или шаблонов в формате `default_workouts.json`) в приложение Gym Tracker на мобильном телефоне (iOS Safari / Android Chrome).

---

## 1. Текущее состояние приложения и уже работающие способы

В проекте уже заложены два механизма, но они имеют свои особенности на телефоне:

1. **Импорт бэкапа / шаблона через JSON-файл в меню «Настройки» (`SettingsModal.ts`)**:
   - В интерфейсе есть кнопка **«Import from JSON»** (`#input-import-json`).
   - На телефоне при нажатии открывается стандартный проводник/файловый менеджер (на iOS — «Файлы» / iCloud Drive / Downloads; на Android — системный файловый менеджер / Google Диск / Загрузки).
   - **Формат**: Ожидается формат `BackupPayload`:
     ```json
     {
       "app": "GymTrackerPWA",
       "version": 1,
       "data": {
         "workouts": [ ... ]
       }
     }
     ```
   - **Ограничение текущей реализации**: Если передать файл формата `default_workouts.json` (где просто массив `[ { "title": "...", "exercises": [...] } ]`), функция `importDatabaseFromJSON` выбросит ошибку: `"Invalid Gym Tracker backup format"`, так как ожидает обёртку `app: "GymTrackerPWA"`.

2. **Кнопка «Reload templates from default_workouts.json»**:
   - Читает шаблоны, вшитые в исходный код при сборке Vite (`src/data/default_workouts.json`).
   - Если сайт задеплоен (на Netlify / Vercel / GitHub Pages) или запущен локально по Wi-Fi, нажатие этой кнопки подтягивает зашитые шаблоны в IndexedDB браузера телефона.

---

## 2. Предлагаемые улучшения для удобства на телефоне

Чтобы пользователю было легко перенести шаблон на телефон, предлагается реализовать следующие доработки:

### Вариант A. Универсальный умный импорт JSON (Файл и Вставка текста)
*Очень часто на телефоне неудобно сохранять `.json` в файлы, а проще скопировать текст из Telegram / WhatsApp / заметки или передать файл.*
1. **Поддержка обоих форматов JSON**:
   - Автоматическое распознавание:
     - Формат 1: Полный бэкап `{ app: "GymTrackerPWA", data: { workouts: [...] } }`.
     - Формат 2: Массив шаблонов `[ { title: "...", exercises: [...] } ]` (как в `default_workouts.json`).
     - Формат 3: Одиночный объект тренировки `{ title: "...", exercises: [...] }`.
2. **Импорт через вставку текста (Paste JSON)**:
   - В модальном окне настроек или отдельном окне добавить кнопку/поле «Вставить шаблон текстом» (Paste JSON text). Пользователь может просто скопировать JSON из мессенджера/заметок и нажать «Загрузить».
3. **Кнопка «Импорт» прямо на главном экране**:
   - Сейчас импорт спрятан в иконке шестеренки `⚙ Settings`. Имеет смысл продублировать кнопку импорта на экране списка тренировок (рядом с «+ New Workout» или в меню).

### Вариант B. Импорт по URL или QR-коду
- Возможность ввести или вставить прямую ссылку (URL) на `.json` (например, GitHub Raw, Pastebin, личный хостинг).
- Приложение скачивает JSON по `fetch` и сразу добавляет тренировку в IndexedDB.

## 3. Пошаговые инструкции для пользователя прямо сейчас (без изменения кода)

Если требуется загрузить шаблон **прямо сейчас**, используя существующую версию:

### Способ 1: Через файл бэкапа (`gym-tracker-import-4days.json`)
1. **Передача файла на телефон**:
   - Отправить файл `gym-tracker-import-4days.json` себе в Telegram («Избранное»), на почту или скинуть через AirDrop / Google Диск / провод.
   - Сохранить файл в память телефона (на iPhone — в приложение «Файлы», на Android — в «Загрузки»).
2. **Загрузка в приложении**:
   - Открыть приложение Gym Tracker в браузере телефона или запустить установленное PWA с домашнего экрана.
   - Нажать иконку **⚙** (шестеренка в правом верхнем углу).
   - Нажать **Import from JSON**.
   - Выбрать сохраненный файл `gym-tracker-import-4days.json`.
   - Подтвердить объединение данных. Шаблоны появятся в списке тренировок!

### Способ 2: Через запуск локального сервера по Wi-Fi
Если телефон и ПК находятся в одной Wi-Fi сети:
1. На ПК в папке проекта запустить:
   ```bash
   npm run dev -- --host 0.0.0.0 --port 3000
   ```
2. Узнать IP-адрес ПК в сети (например, `192.168.1.45`).
3. На телефоне открыть `http://192.168.1.45:3000/`.
4. Все шаблоны из `src/data/default_workouts.json` подгрузятся автоматически при первом входе, либо можно нажать ⚙ -> **Reload templates from default_workouts.json**.
5. Установить PWA на экран «Домой» (Safari: Поделиться -> На экран «Домой»; Chrome: меню ⋮ -> Установить приложение). После этого приложение и шаблоны останутся на телефоне офлайн!

- Расширить `importDatabaseFromJSON` и добавить `importWorkoutsFromText(jsonString: string)`:
  - Проверять структуру входящего JSON.
  - Если это `DefaultWorkoutTemplate[]` или одиночная тренировка — конвертировать в объекты `Workout` (генерировать `UUID`, `order_index`, маппить сеты) и сохранять в IndexedDB.
  - Автоматически регистрировать упражнения в `user_custom_exercises` для автокомплита.
